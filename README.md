# modele-essai

Essai du modèle de projet, à archiver

Ce dépôt sert à vérifier, en conditions réelles, la naissance d'un projet par le lot 1 de
`modele-projet` : noms des contrôles de la CI, refus d'envoi vers `main`, garde de Claude. Il
sera archivé une fois ces contrôles faits.

## Pour s'y retrouver

- [`CLAUDE.md`](CLAUDE.md) : l'état du projet, les commandes, ce qui fait foi, les invariants.
- [`docs/00-brief-initial.md`](docs/00-brief-initial.md) : la demande de départ.
- [`docs/cadrage.md`](docs/cadrage.md) : le cadrage, livrable de la phase 0.
- [`docs/decisions/`](docs/decisions/) : les décisions d'architecture (ADR).

Né du modèle `EdouardZemb/modele-projet` ; se met à jour par `copier update`.
